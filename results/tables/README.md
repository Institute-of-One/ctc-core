# results/tables — which file is which

Generated by `scripts/check_tables.py --write-readme`. Do not edit by
hand: the register lives in that script, and the same register is what
`check_tables.py` enforces.

**The plainest names are not the reported ones.** `eval_hqcolon.csv` is a
hand run from 2026-09-10 and `centerline_batch.csv` is the prototype
baseline. The manuscript's numbers come from the `_auto` pair.

## Reported — the manuscript's numbers

| file | what it is |
|---|---|
| **acquisition.csv** | Acquisition parameters |
| **centerline_auto.csv** | Centerline run, 60 series. The 'after' column of Table 2 |
| **centerline_batch.csv** | Prototype baseline, 60 series. The 'before' column of Table 2 |
| **centerline_perturbation.csv** | Centerline perturbation experiment |
| **clustered_statistics.csv** | Patient-cluster intervals (scripts/stats_clustered.py) |
| **cohort_characteristics.csv** | Cohort table |
| **cohort_lesions.csv** | Every annotated lesion in the cohort, decoded from the collection's published column key. Table 12 (scripts/report_cohort_lesions.py) |
| **coverage_anatomy.csv** | Coverage by position along the reference centerline, and the fluid or collapsed volume the gas mask excludes. Tables 8 and 9 (scripts/analyse_coverage_anatomy.py) |
| **eval_hqcolon_auto.csv** | Reference evaluation. Table 3: restricted to the 13 patients not inspected it is the primary column, whole it is the development-tuned column |
| **eval_hqcolon_batch.csv** | The 2026-08 prototype configuration evaluated against the same HQColon reference, from its own masks and paths in data/centerline/batch. Table 4, the comparator |
| **gas_attenuation.csv** | Attenuation of the colonic gas inside the reference mask, and the share each candidate threshold admits. Table 10 and the Methods (scripts/measure_gas_attenuation.py) |
| **image_noise.csv** | Image noise measured in the cohort itself: the local standard deviation of homogeneous soft-tissue windows and its in-plane autocorrelation. The Methods, and the level injected into the phantoms (scripts/measure_image_noise.py) |
| **indices.csv** | Quantitative indices, 60 series |
| **polyp_phantom_accuracy.csv** | Phantom polyp measurement |
| **polyp_realism.csv** | Polyp measurement under noise, a fluid interface and adhesion to a wall or fold. Table 11 and Supplementary file 8 (scripts/eval_polyp_realism.py) |
| **prone_supine_agreement.csv** | ICC and limits of agreement, 28 pairs |
| **stratified_acquisition.csv** | The results by manufacturer, kernel, slice thickness, tube voltage and tube current. Supplementary file 6 (scripts/stratify_acquisition.py) |
| **threshold_sweep.csv** | Each threshold varied one at a time, masks and path rebuilt per setting. Table 10 (scripts/sweep_thresholds.py) |
